# LHP for Visual Studio Code

Native YAML editing with guided pipeline graphs and forms for Lakehouse Plumber.

**Development status:** initial implementation for the unreleased LHP 0.9.3
integration build. Installable VSIX delivery is being prepared; this extension
has not been published to the Visual Studio Marketplace.

See [PLAN.md](PLAN.md) for the accepted scope and architecture, and
[TODO.md](TODO.md) for implementation and verification progress.
