# Architecture

The extension host owns trust, project selection, interpreter selection, subprocesses, documents and filesystem containment. React renders graphs and schema/help-driven forms. The Python adapter imports only `lhp.api`, package metadata and the Python standard library.

`src/shared/protocol.ts` is the single typed contract. Host requests are allowlisted and validated at runtime. Project-bound requests carry project identity and snapshot revision; mutations additionally carry native document versions. Source addresses combine project-relative path, YAML document index, YAML key/index path and zero-based UTF-16 ranges. They support multi-document streams and flowgroups arrays inside mapping documents. Unsupported root sequences remain canonical LHP errors.

Native `TextDocument` objects are authoritative. A form submits a complete cloned mapping; the host applies a recursive YAML CST patch to the matching source address. Unknown fields and unchanged nested mapping comments survive. Graph edits are guarded immediately before `WorkspaceEdit`; newer text wins over stale form submissions. Native undo/redo remains available when YAML is invalid. Generated template, blueprint and monitoring actions expose instance/definition/configuration navigation instead of pretending to own action YAML.

Each Python request has a request ID and isolated process. NDJSON contains structured events, results and errors; incidental stdout is redirected away from the protocol. Selected interpreter execution uses argv arrays and no shell. POSIX process groups and Windows `taskkill /T` terminate descendants on cancellation, timeout or disposal. The bridge rejects traversal, escaping symlinks, unsupported operations and unsaved full generation. Bounded error reporting avoids dumping Python tracebacks or package installation output into the UI.

The core public API owns parsing, resolution, dependency analysis, catalogues, validation and rendering. `inspect_editor_project` returns canonical action/flowgroup/pipeline graphs and source provenance. The TypeScript normalizer translates DTO casing and graph identities; it does not parse SQL or reconstruct dependencies from guessed strings. Installed action help supplies subtype skeletons and form descriptions, while canonical validation remains authoritative for conditional constraints.

Snapshot/validation/preview use isolated temporary mirrors for unsaved documents. Full generation uses the saved real project with explicit `output_dir=project_root/generated/env`, no pipeline filter, and the public bundle enablement policy. Editor API pipeline configuration paths stay project-relative; the saved-generation facade receives the contained absolute path because its loader uses the process working directory. The bridge pins the supported 0.9.2/0.9.3 family and requires all editor capabilities; package metadata remains honest.

Project, environment, runtime and native source changes invalidate asynchronous results. A last valid graph can remain visible with a stale marker while syntax is repaired. Preview URIs are read-only and their providers emit change events that replace expired content. Generation ignores its own filesystem write notifications while a dirty native user edit still cancels the operation. Validation issues retain canonical detail and source navigation; Problems updates recheck the active revision before publication.

Red Hat YAML's contributor API is registered once. A synchronous resource callback selects the per-project installed schema; content lives under `lhp-schema:` with a catalogue fingerprint. Pipeline authoring uses a union of flowgroup and blueprint-instance schemas, including mixed document streams. Semantic completions and definitions supplement the existing language service. No user YAML settings are overwritten to associate schemas.

The webview has a strict local-resource CSP with a nonce, no network access and no embedded Monaco. React escapes displayed content. The host resolves all file paths. Secrets and Databricks authentication stay with the user's normal tools; the extension never connects to a cloud workspace itself.

Tests are split across pure mutation/path/protocol and DTO normalization tests, real Python bridge subprocess tests, React interaction tests, and real VS Code extension-host tests. The desktop CI matrix runs on Linux, macOS and Windows with the same pinned core commit and vendor YAML dependency. Existing LHP E2E tests remain outside this repository's edit scope.
