# Lakehouse Plumber

Write declarative YAML and explore the same pipeline through guided forms
and graphs. Open SQL, Python and configuration in native VS Code editors.

Select an environment before preview or generation. In Configuration, open
Sandbox to choose Off (the full project) or configure `.lhp/profile.yaml` for
selected pipelines. Show all changes the view only. Preview renders source;
generation replaces `generated/<environment>` and synchronises managed
`resources/lhp` in either mode.
